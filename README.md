# TASSEL CLI Skill

This project provides a Claude Code skill that helps users work with the TASSEL 5 command line.

The skill can help create and troubleshoot pipelines including:
* genotype filtering
* file conversion
* GWAS
* PCA
* kinship
* imputation
* GBSv2

## Installation

Clone this repository into your Claude Code skills folder:

```bash
git clone https://github.com/YOUR_USERNAME/tassel-cli-skill.git ~/.claude/skills/tassel-cli
```

Replace `YOUR_USERNAME` with the GitHub username or organization that hosts the repository.
